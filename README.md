# Amit Kashyap — Design in Motion

Second portfolio concept (dark, motion-first). Vite + three.js.

- `npm install`
- `npm run dev` → http://127.0.0.1:5178/
- `npm run build` → `dist/` (BASE_URL-safe; deploy with `vite build --base=/repo-name/`)

Hero ribbon is adapted from the free "Video Ribbon" prompt on motionsites.ai (prompt text/code is free to reuse per their terms);
all cards use Amit's own reels and designs. The ink-brush reveal, chapters, reels wall, timeline and marquees are original code.
